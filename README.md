## 🛠️ How to Deploy to Any WordPress Site

### Option A: Using WordPress Admin Dashboard
1. **Install Theme**:
   - Go to **Appearance > Themes > Add New > Upload Theme**.
   - Choose `oakline-sr22-theme.zip` and click **Install Now**, then **Activate**.
2. **Import Content**:
   - Go to **Tools > Import > WordPress** (install the WordPress Importer plugin if prompted).
   - Upload `oakline-sr22-content-export.xml` and click **Upload file and import**.
   - Assign posts to your admin user and submit.
3. **Configure Reading Settings**:
   - Go to **Settings > Reading**.
   - Set "Your homepage displays" to **A static page**.
   - Homepage: **Home**
   - Posts page: **Blog**
   - Click **Save Changes**.
4. **Set Permalinks**:
   - Go to **Settings > Permalinks**.
   - Select **Post name** (`/%postname%/`) and click **Save Changes**.

### Option B: Direct File Copy
1. Copy the `oakline-sr22-theme` folder into your WordPress installation under `wp-content/themes/`.
2. Activate the theme via the admin panel.
3. Import `oakline-sr22-content-export.xml` via **Tools > Import**.
